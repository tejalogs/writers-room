# Stage 1 — Brief

**Input:** the user's request + the brand pack.
**Output:** `01-brief.md`

Fill every field. If the user didn't give one, choose a sensible default and mark it `(assumed)`. Ask the user only if a missing field would change the whole piece (usually: format, audience, or the keyword for a blog).

```markdown
# Brief: <working title>

- Format: blog (post type: answer | playbook | POV | story | comparison | data) / podcast (solo | two-host | interview guide) / social (LinkedIn | X post | X thread | Instagram caption | YouTube/episode description | short-video script) / all formats from one idea
- Length: <words or minutes>
- Market / spelling: <e.g. UK, US>
- Audience segment: <one segment from BRAND.md, described as a person in one sentence>
- What they're searching / feeling right now: <their words, not ours>
- Primary keyword (blog): ...
- Secondary keywords / questions (blog): ...
- The belief we're overturning: "..."
- The truth we're landing: "..."
- The action they'll take after: ...
- CTA (from BRAND.md): ...
- Must include / must avoid (from user): ...
- Sources supplied by user: ...
- What we **know** (with source) vs what we're **assuming**: ...
- What is everyone else overlooking about this topic? ...
- What would someone from a completely different field notice here? (a psychologist, an economist, a recruiter, a teacher) ...
```

## Gate

The belief and the truth are both filled and actually in tension. "People don't know X" → "X matters" is not tension. "People believe A" → "actually not-A, here's why" is tension.
