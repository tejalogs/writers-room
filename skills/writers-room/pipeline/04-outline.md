# Stage 4 — Outline (beat sheet)

**Input:** stages 1–3, the format structure file, `craft/bridges-and-loops.md`, blogs: `craft/seo-aeo.md`.
**Output:** `04-outline.md`

## Do

Write a **beat sheet**: one line per beat (a beat = one move in the argument or story, ~100–250 words when drafted). For each beat:

```
<n>. [<segment / H2>] <what happens in this beat> | material: <story id / fact> | loop: open X / close Y | bridge out: <but / so / question / time jump...> | ~<words>
```

Then add three ledgers below the beats:

1. **Loop ledger:** every loop, the beat it opens, the beat it closes. The open-loop count must stay above zero until the final section.
2. **Setup/payoff ledger:** every planted image, number or line, and where it returns. The cold-open image must return in the close.
3. **Belief arc:** one line each: what the reader believes at the start, after the middle, at the end.

Blogs also list: the H2s as final wording (real questions), where the answer block, key takeaways and FAQ go, and the 2–4 internal links.

## Gate

- Read only the "bridge out" column top to bottom: no "and then".
- Every beat has material. A beat with no story, fact or example gets cut or marked `[NEEDS ...]`.
- Word counts add up to the target length ±10%.

## ⏸ Checkpoint

Unless the user said "autopilot", **stop here**. Show the outline as a short beat list (one line per beat) plus the open `[NEEDS …]` items, and ask "Draft it?" Don't draft until they say yes.
